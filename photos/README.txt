PHOTOS FOLDER

Every photo must be a .webp file. Put each photo in the folder for its section:

  home/              Home page: 3 hero pictures (hero-1, hero-2, hero-3) and store-photo
  categories/        Shop by Category small icons (one per category: fashion.webp, jewellery.webp …)
  products/         Every product photo, named by product id in lowercase (lvn-001.webp, lvn-017.webp …)
  favourites/        Everyday Favourites (fav-01.webp …)
  highlights/        Highlights on Home (hl-01.webp …)
  seasons/           Season tiles (summer.webp, monsoon.webp, winter.webp, wedding.webp)
  season-items/<season>/   Items inside each season (file name = item name in lowercase, spaces become -)
  festivals/         Festival tiles (diwali.webp …)
  festival-items/<festival>/   Items inside each festival (file name = item name in lowercase)
  brands/            Brand logos (brand-1.webp … brand-6.webp)
  gallery/           Store photos for the Gallery section
  lookbook/          Story pictures (look-01.webp …)

The exact file name for each item is written in its data file (the img line). Copy that path
and create the file at that place. If a photo is missing, the space stays blank and the name still shows.
